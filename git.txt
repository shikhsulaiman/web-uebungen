git status                        # Zeigt: was hat sich geändert?
git add .                         # Markiert alle Änderungen für den nächsten Commit
git commit -m "Beschreibung"     # Macht einen Speicherpunkt mit Kommentar
git push                          # Lädt Commits zu GitHub hoch
git pull                          # Holt Änderungen von GitHub
git clone <URL>                   # Lädt ein Repo erstmals herunter


Repository („Repo") – Ein Projekt. Ein Ordner mit Code, der von Git überwacht wird.

Branch („Zweig") – Eine parallele Arbeitslinie. Du kannst eine neue Funktion in einem
eigenen Branch entwickeln, ohne den Hauptcode zu beeinflussen.
