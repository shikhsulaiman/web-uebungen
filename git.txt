
Repository („Repo") – Ein Projekt. Ein Ordner mit Code, der von Git überwacht wird.

Branch („Zweig") – Eine parallele Arbeitslinie. Du kannst eine neue Funktion in einem
eigenen Branch entwickeln, ohne den Hauptcode zu beeinflussen.

README – Eine Datei in jedem Repo, die das Projekt erklärt.in Markdown (.md)




git init                # Macht aus einem Ordner ein Git-Repo
git status              # Zeigt: was hat sich geändert?
git add .               # Markiert alle Änderungen für den nächsten Commit
git commit -m "Beschreibung"   # Macht einen Speicherpunkt mit Kommentar
git push                # Lädt Commits zu GitHub hoch
git pull                # Holt Änderungen von GitHub
git clone <URL>         # Lädt ein Repo erstmals herunter (Kopie auf den eigenen Rechner machen)

wichtigsten Branch-Befehle 

git branch                          # Liste aller lokalen Branches
git branch -a                       # Liste inkl. GitHub-Branches
git branch neuer-name               # Neuen Branch erstellen
git checkout neuer-name             # Zu einem Branch wechseln
git checkout -b neuer-name          # Erstellen UND wechseln in einem
git branch -d alter-name            # Lokal löschen (sicher)
git branch -D alter-name            # Lokal löschen (mit Force)
git push origin --delete alter-name # Auf GitHub löschen
git merge anderer-branch            # Anderen Branch in den aktuellen einbauen
