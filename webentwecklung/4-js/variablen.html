Variablen benennen

Es gibt zwei Regeln für die Namensgebung von Variablen:

  1. Der Name darf nur aus Buchstaben, Zahlen und den Symbolen.
  2. Das erste Zeichen darf keine Zahl sein $ und _ bestehen.

Es gibt außerdem einige weite Punkte zu beachten

  • Groß- und kleinschreibng spielt eine Rolle
  • Nicht-lateinischee Buchstaben sind erlaubt, können aber zu Problem führen
  • Einige Namen sind bereits reseriviert, da sie von JS verwendet werden:
    • let
    • class
    • return
    • function
